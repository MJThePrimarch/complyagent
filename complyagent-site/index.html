How it actually works

Four tools, orchestrated by an agent built on the Strands Agents SDK, reasoning through the pipeline via Claude on Amazon Bedrock.

1
Load
Reads the chosen control dataset and groups every control by status.
2
Classify
Ranks failing and partial controls by severity, weighted by control family.
3
Draft
Writes a remediation ticket for each of the top gaps, with a suggested owner.
4
Summarize
Produces the overall score, top-5 risks, and an exec-ready email draft.

Not locked to one standard

The scoring and ticket-drafting logic works the same regardless of which framework you're assessing against.
